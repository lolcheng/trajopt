# 约束总结文档

基于 `trajopt_sdf.py` 的约束分析

## 变量定义

### 优化变量

**C++实现** (共 200 个):
- **多项式系数** (50个):
  - `cbx, cby, cbz, cpsi`: base轨迹系数 (4 × 5 = 20)
  - `clx, cly, clz`: 左轮轨迹系数 (3 × 5 = 15)
  - `crx, cry, crz`: 右轮轨迹系数 (3 × 5 = 15)

- **接触力** (150个):
  - `fLx, fLy, fLz`: 左轮接触力 (3 × 25 = 75)
  - `fRx, fRy, fRz`: 右轮接触力 (3 × 25 = 75)

**Python参考实现** (共 650 个):
- **多项式系数** (50个): 与C++相同
- **接触力** (600个): `n_sample = 100`，所以是 6 × 100 = 600个

### 轨迹评估
- 使用多项式基函数在 `s ∈ [0,1]` 上评估
- **C++实现**: `n_sample = 25` (间距约20cm，适合5m左右的轨迹)
- **Python参考**: `n_sample = 100` (间距约5cm)
- 多项式阶数: `N_COEFF = 5`

## 硬约束 (Hard Constraints)

### ✅ 1. 边界条件约束 [已实现]
- **C++实现**: 20个等式约束
  - Base边界：8个（起点和终点的base位置和yaw）
  - 轮子初末点：12个（左右轮在起点和终点的x, y, z位置，确保触地且在base附近）
- **Python参考**: 8个等式约束（仅base边界）
- 起点 (s=0):
  - `Xb(0) = XB0 = 2.5`
  - `Yb(0) = YB0 = 1.0`
  - `Zb(0) = ZB0 = h(XB0, YB0) + CLEAR_Z`
  - `Psi(0) = PSI0 = -π/2`
  - 轮子初末点约束（C++特有）：确保轮子在起点和终点触地且在base附近

- 终点 (s=1):
  - `Xb(1) = XB1 = 2.5`
  - `Yb(1) = YB1 = -3.5`
  - `Zb(1) = ZB1 = h(XB1, YB1) + CLEAR_Z`
  - `Psi(1) = PSI1 = -π/2`
  - 轮子初末点约束（C++特有）：确保轮子在起点和终点触地且在base附近

### ✅ 2. 轮子-中心距离约束 (2×n_sample = 50个不等式约束) [已实现]
- 左轮-中心距离: `WHEEL_BASE_MIN² ≤ dist²_L ≤ WHEEL_BASE_MAX²`
- 右轮-中心距离: `WHEEL_BASE_MIN² ≤ dist²_R ≤ WHEEL_BASE_MAX²`
- 其中: `dist² = (Xb - Xw)² + (Yb - Yw)² + (Zb - Zw)²`
- 参数: `WHEEL_BASE_MIN = 0.4`, `WHEEL_BASE_MAX = 1.2`

### ✅ 3. 左右轮距离约束 (n_sample = 25个不等式约束) [已实现]
- 左右轮距离: `WHEELS_MIN² ≤ dist² ≤ WHEELS_MAX²`
- 其中: `dist² = (Xr - Xl)² + (Yr - Yl)² + (Zr - Zl)²`
- 参数: `WHEELS_MIN = 0.1`, `WHEELS_MAX = 0.8`

### ✅ 4. 防交叉约束 (n_sample = 25个不等式约束) [已实现]
- 在base坐标系下: `yL_base ≥ yR_base`
- 其中:
  - `u_lat = [-sin(psi), cos(psi)]` (横向单位向量)
  - `yL_base = (Xl - Xb) · u_lat_x + (Yl - Yb) · u_lat_y`
  - `yR_base = (Xr - Xb) · u_lat_x + (Yr - Yb) · u_lat_y`

### ✅ 5. 法向力上限约束 (2×n_sample = 50个不等式约束) [已实现]
- `fLn ≤ fN_max = MASS × (GRAVITY + 1.0)`
- `fRn ≤ fN_max`
- 其中: `fLn = fL · nL`, `fRn = fR · nR` (法向分量)

## 软约束 (目标函数中的惩罚项)

### ✅ 1. Smoothing Penalty (平滑项) [已实现]
- 对轨迹的二阶差分进行惩罚: `(v3 - 2*v2 + v1)²`
- 应用于: `Xl, Yl, Zl, Xr, Yr, Zr, Xb, Yb, Zb, Psi`
- 权重: `1.0 / n_sample`

### ✅ 2. Regularization (正则化) [已实现]
- 对多项式系数的L2范数惩罚: `||coeff||²`
- 权重: `1.0`

### ✅ 3. Wheel-Base Distance Nominal (轮子-中心距离目标) [已实现]
- 惩罚偏离标称距离: `(dist² - WHEEL_BASE_NOMINAL²)²`
- 参数: `WHEEL_BASE_NOMINAL = 0.8`
- 权重: `1.0 / n_sample`

### ✅ 4. Wheels Distance Nominal (左右轮距离目标) [已实现]
- 惩罚偏离标称距离: `(dist² - WHEELS_NOMINAL²)²`
- 参数: `WHEELS_NOMINAL = 0.5`
- 权重: `1.0 / n_sample`

### ✅ 5. Wheel-Terrain Distance (轮子-地形距离) [已实现]
- 惩罚轮子与地形距离: `(Zl - H_l)² + (Zr - H_r)²`
- 权重: `1.0 / n_sample`

### ✅ 6. Yaw-Path Alignment (偏航-路径对齐) [已实现]
- 惩罚偏航角与路径切线方向不对齐: `(1 - cos(alignment))²`
- 权重: `W_YAW_ALIGN / n_sample = 50.0 / n_sample`

### ✅ 7. Contact Stiffness (接触刚度) [已实现]
- 惩罚接触力与穿透量弹簧模型不符: `(fLn - K_CONTACT × pen_l)²`
- 参数: `K_CONTACT = 500.0`
- 权重: `W_CONTACT_STIFF / n_sample = 1000.0 / n_sample`

### ✅ 8. Force Balance (合力平衡) [已实现]
- 惩罚合力不为零: `||fL + fR + [0, 0, -mg]||²`
- 权重: `W_FORCE_BAL / n_sample = 10.0 / n_sample`

### ✅ 9. Torque Balance (合矩平衡) [已实现]
- 惩罚合矩不为零: `||rL × fL + rR × fR||²`
- 权重: `W_TORQUE_BAL / n_sample = 10.0 / n_sample`

### ✅ 10. Friction Cone Violation (摩擦锥违反) [已实现]
- 惩罚摩擦锥违反: `max(0, ||f_t||² - μ² × f_n²)²`
- 惩罚拉力: `max(0, -f_n)²`
- 参数: `MU_FRICTION = 0.6`
- 权重: `W_FRIC_CONE / n_sample = 1000.0 / n_sample`

## RBF 地形相关

### RBF 地形高度
- `H(x, y) = Σ w_i × exp(-0.5 × r² / σ²)`
- 其中: `r² = (x - cx_i)² + (y - cy_i)²`
- 参数: `RBF_CENTERS`, `RBF_WEIGHTS`, `RBF_SIGMA`

### 地形梯度
- `∂H/∂x = Σ w_i × exp(-0.5 × r² / σ²) × (-dx / σ²)`
- `∂H/∂y = Σ w_i × exp(-0.5 × r² / σ²) × (-dy / σ²)`

### 表面法向量
- `n = normalize([-∂H/∂x, -∂H/∂y, 1])`
